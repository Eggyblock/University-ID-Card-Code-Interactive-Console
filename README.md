# University-ID-Card-Code-Interactive-Console

Repositorio para la primera práctica de la materia Lenguajes y Paradigms de Computación (2026-2) de la Universidad EAFIT. Contiene las soluciones desarrolladas en los paradigmas funcional (Haskell) y lógico (Prolog) para la asignación de códigos de identidad estudiantil basados en la clasificación de Nicómaco.
